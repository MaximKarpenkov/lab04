## 4. Индивидуальный вариант: Числа, кратные 3 (`variant_2.py`)

Мой вариант: **Вариант 6 — Числа, кратные 3**.

Программа запрашивает `количество_чисел >= 0`, а затем `количество_чисел` целых чисел. Одним циклом находит количество и сумму значений, удовлетворяющих условию (число кратно 3). Ноль кратен любому ненулевому целому. Если подходящих чисел нет, оба результата равны нулю. Список не используется.

### Пример расчёта (контрольный набор из таблицы: `количество_чисел = 7`, числа `-12, -3, 0, 2, 10, 15, 20`):

* **Входные данные:**
  * `количество_чисел = 7`
  * Числа: `-12`, `-3`, `0`, `2`, `10`, `15`, `20`
* **Ожидаемый результат:**
  * Количество: `4` (числа `-12`, `-3`, `0`, `15`)
  * Сумма: `0` (`-12 + (-3) + 0 + 15 = 0`)
